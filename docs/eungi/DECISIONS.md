# 결정 기록 (은기, 0\~3단계 지도 만들기)

0\~3단계를 만들면서 정한 것을 모았습니다. 각 단계 문서(STEP0\~3.md)의 "이 단계에서 정한 것"과 같은 내용이고, 단계마다 자세한 설명과 예시는 STEP 문서에 있습니다.

**읽는 법**
- **출처** 칸이 "DESIGN.md 제안과 같음"이면 [DESIGN.md](../DESIGN.md) 4절의 제안을 그대로 따른 것입니다.
- "새로 정함"은 DESIGN에 없어서 구현하면서 정한 것, "교차 검토로 정함"은 두 검토자(설계 쪽, 구현 쪽)가 코드를 직접 돌려 보고 문제를 찾아 고치면서 정한 것입니다.
- 모두 아직 **팀 합의 전**입니다. 회의에서 합의된 것만 DESIGN.md 4절로 옮기고 상태를 "합의"로 바꿉니다.
- 결정을 바꿀 때는 그 줄을 고치고, 왜 칸에 "(변경: 이전에는 ...)"을 덧붙입니다.
